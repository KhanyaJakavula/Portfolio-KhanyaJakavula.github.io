4. Lessons Learned

  • Planning helps make project requirements clearer.
  • User experience should be considered when designing application screens.
  • Figma is useful for creating and organising interface designs.
  • Trello helps with task organisation and progress tracking.
  • Communication and teamwork are important in group projects.
  • Regularly reviewing work helps identify areas for improvement.

6. Overall Personal Reflection

Reflecting on my experience with Pulse Guard, I can say that the project helped me understand how Agile principles are applied when working as part of a team. I gained experience in organising tasks, following project progress and focusing on the needs of users when designing an application.

My role as Mobile UI/UX Designer allowed me to practise my design skills using Figma. I also learned that communication and collaboration are important because the work completed by each team member contributes to the final application.
